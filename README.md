# UNIDAD-2-BASE-DE-DATOS-EJERCICIO-4
Se debe diseñar un modelo entidad-relación (MER) para representar el funcionamiento de una tienda online, organizando la información de los productos, categorías, clientes, pedidos y transportistas.

El sistema debe permitir registrar:
- Productos: código SKU, nombre, descripción, precio y stock disponible.
- Categorías: organizar los productos en categorías y subcategorías.
- Clientes: ID, correo electrónico, contraseña, nombre y varias direcciones de envío.
- Pedidos: número de orden, fecha y hora, estado y monto total.
- Detalle del pedido: registrar los productos comprados, la cantidad solicitada y el precio unitario al momento de la compra.
- Transportistas: CUIT, razón social, teléfono y número de seguimiento del envío.
También se deben definir las relaciones y cardinalidades, teniendo en cuenta que un cliente puede realizar varios pedidos, que un pedido puede contener varios productos y que cada pedido es enviado mediante un transportista.
